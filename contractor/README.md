# Contractor

## Requirements
- create an app for homeowners connect with contractors who can create, build or fix anything in a home.
- pattern this app after https://www.thumbtack.com
- Use typescript as the backend language, use nestjs as the backend framework. Use ORM to communicate with the database.
- typescript tutorial will be from this project just FYI.
- Use react as the framework for the frontend project along with tailwind css.
- have one app for both homeowners to create a profile and search for contractors and contractors to create profile, updload images and accept projects from homeowners
- use hasura v2 as the graphql engine and postgres as the database. have all read endpoints use graphql directly. all create, update, and delete endpoints should be hosted on the backend nestjs project.
- use docker composer for any services like hasura that this app needs.
- name the app contractor.
